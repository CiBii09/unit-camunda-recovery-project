# Camunda workflow models

This directory is reserved for the Onboarding Abandonment Recovery process models. Keep versioned BPMN and DMN source files here; do not commit generated deployment artifacts.

## Structure

`bpmn/` stores BPMN process models and related documentation.

`dmn/` stores decision tables used by the process.

`tests/` stores model validation and decision-table test data.

No process model or eligibility policy is defined yet. Add those only after the business flow, task types, and decision inputs/outputs have been agreed.
